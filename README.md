# Military Supply Chain Management System Database

This repository contains the SQL script compatible with SQLite to create the structure and initial data of a database focused on managing military resources, logistics, and operations.

## Included Tables
* **MilitaryPersonnel:** Personnel records and service history.
* **BaseDestinations:** Military bases and commanding officers.
* **Equipment & EquipmentCategories:** Equipment inventory and classification.
* **MilitarySuppliers:** Suppliers and defense contractors.
* **LogisticsTransport:** Logistics transport vehicles.
* **Missions & AssignmentDetails:** Mission tracking and resource assignments.
